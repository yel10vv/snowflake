# Snowflake

Простая реализация алгоритма Snowflake для генерации ID.
```
41 бит выделено под временную метку равную 1 мс
10 бит под номер машины
12 бит под номер последовательности
```

## Установка

Для установки библиотеки выполните команду в терминале:

```bash
go get github.com/yel10vv/snowflake
```

## Использование

Минимальный пример кода, демонстрирующий работу библиотеки:

```go
package main

import (
	"fmt"
	"log"
	"time"

	"github.com/yel10vv/snowflake"
)

func main() {
	// 1. Инициализация генератора Snowflake.
	// Передаем ID машины (например, 42). 
	// Опцию WithStartTime можно не указывать — тогда автоматически установится текущее время.
    customStartTime := time.Date(2026, 1, 1, 0, 0, 0, 0, time.UTC)
	sf, err := snowflake.New(42, snowflake.WithStartTime(customStartTime))
	if err != nil {
		log.Fatalf("Ошибка инициализации: %v", err)
	}

	// 3. Генерируем уникальный ID
	id, err := sf.NextID()
	if err != nil {
		// Ошибка возвращается только в случае исчерпания бит, отведенных под метку времени
		log.Fatalf("Критическая ошибка: исчерпаны биты времени: %v", err)
	}

	fmt.Printf("Сгенерирован уникальный ID: %d\n", id)
}
```
